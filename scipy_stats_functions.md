# SciPy Stats Learning Roadmap

| Topic | Important Functions | Purpose |
|---|---|---|
| Descriptive Statistics | `describe()`, `mode()`, `variation()` | Summarize data |
| Measures of Spread | `iqr()`, `sem()` | Understand variability |
| Standardization | `zscore()` | Calculate standardized values |
| Skewness and Kurtosis | `skew()`, `kurtosis()` | Understand distribution shape |
| Probability Distributions | `norm`, `uniform`, `binom`, `poisson` | Work with probability distributions |
| Probability Calculations | `pdf()`, `cdf()`, `ppf()`, `rvs()` | Calculate probabilities and generate values |
| Correlation | `pearsonr()`, `spearmanr()` | Measure relationships |
| Statistical Tests | `ttest_ind()`, `ttest_rel()`, `ttest_1samp()` | Compare means |
| Categorical Tests | `chi2_contingency()` | Test relationships between categorical variables |
| Normality Tests | `shapiro()`, `normaltest()` | Assess normality |
